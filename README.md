## 三条设计取舍

1. **情绪是滤镜，不是人设。** 插件只影响语气、句长、标点、用词冷热；不改身份、不改称呼判定、
   不改气泡数量与排版。危机信号（自伤/轻生）会**立刻压掉全部傲娇与玩笑**。
2. **记忆是选择，不是仓库。** 每轮都重新算「哪几条现在值得想起来」：相关、重要、新鲜、强度。
   没被用到的自然淡掉，被反复想起的才留得住；说错就扣分（价值回传）。
3. **不刷屏。** 群里执行命令时，图和大段文字发到发指令那个 QQ 的私聊，群里只留一句提示；
   失败信息留在原地，别让人去私聊找报错。

## 快速开始

1. **装**：把仓库目录放进 AstrBot 的 `data/plugins/`，重启或重新启用插件。
2. **认人**：面板「人格定制」里填你的平台 ID（专属用户）；群里她会自动闭嘴不透露关系。
3. **自检**：面板默认是**傻瓜模式**，「管理」页会告诉你哪里没配好，一次点「一键套用推荐配置」。

## 情绪与身体

**三层结构**

```
即时情绪 emotion   半衰期 ~4 分钟     一句话就能点着，也退得快
      ↓ 慢慢带动
心境     mood      半衰期 ~1.5 小时   被反复的情绪带偏，留得久
      ↑ 都围绕它衰减
气质基线 baseline  tsundere: +0.08 / +0.22 / +0.30
```

40 种情绪原型各带自己的 PAD 区域与「这时候她会怎么说话」；识别不到原型时用
Plutchik 八族 + 中文情感词汇本体（7 大类 21 小类）兜底，面板「理论」页可查。

**身体（下丘脑那一层）**：昼夜节律（凌晨 4 点最没精神、14:30 犯困、20:00 最精神）、
能量、饥饿、压力半衰期 2 小时、着凉（累 + 压力才有概率，6~20 小时自愈）、生理周期
（28 天周期、5 天经期，可整体关掉）。身体**只给情绪一层偏移**，不覆盖情绪、不改人设。

**仿人脑三功能**：习惯化（同一刺激反复出现按 `1/(1+0.35n)` 抑制，地板 0.25）、
共情（对方情绪按熟悉度 10%~38% 渗进慢心境）、奖励预测误差（落差 >0.55 才给唤起）。

**日程**：按日期判今天是什么日子 —— 上学日 / 周末 / 法定节假日 / 寒暑假 / 调休上课，
天数全部由起止日期现算（春节 9 天、国庆 7 天、暑假 53 天各不相同）。
法定假按国办通知逐年核对，农历三节用 2024~2030 的表兜底，未覆盖年份自动降级。

## 记忆

**分层**：`pinned` = 档案层（永不过期）｜`fact/preference/relation` = 长期层｜`event` = 一次性层。

**四力打分**（移植 dsh-unified-memory）：相关（BM25）/ 重要 / 新鲜（半衰期按重要度 180·60·21 天）/
强度（被用过几次）。邻居按共享关键词做**超图传播**（默认关，开了会改变排序）。
向量没配就只用 BM25，不会因此什么都想不起来。

**遗忘与间隔**：唤醒强度从「上次想起」算，想过越多次忘得越慢（有封顶）。

**价值回传**：用户说「对 / 不是这样」就是对上一轮记忆的一次评价，正向 +0.12、负向 −0.18，
沿超图邻居按 0.4 带一跳。**经验结晶**：同话题 ≥3 条、均价 ≥0.8 的记忆压成一条 `kind=policy`
的「经验」卡，维护循环里每 20 圈跑一次，同组不重复。

**知识树**（移植 dsh-knowledge-canvas）：树 → 节点，按会话激活，只在她说话的那个会话里出现；
模型想改节点先进待审队列，你批准才生效。和记忆的区别：记忆是聊天里捞的碎片，
知识树是你自己整理的结构。

**隐私三道闸门**：拒绝名单（既不采集也不注入）、`/忘我`（本人一键删光，立即硬删）、
敏感信息降级（证件号/住址/学校/真名 → 只在本人私聊里出现，绝不进群聊）。

## 表达与拟人

- **拟人分段**：按标点把一条回复拆成 1~3 口气，按字数算停顿；代码块/表格/引号整块保护；
  与 TTS 插件兼容（带 `[TTS]` 标记不分段，语音与文字重复只发一遍）。
- **去 AI 味**：本地词表打分（AI 高频词、套路句型、句长过匀、破折号、四字格、项目符号…），
  不达标打回重写，越改越差保留原版。三种模式：只检查 / 自动改 / 关。
- **表达示例**：从真实对话里学她以前怎么说话，默认先审后注入，可批准/拒绝/回滚。
- **模仿指定 QQ**：只采名单里那几个 QQ 说过的话，算句长/标点/语气词/句末字/表情率，
  凑够 20 条注入参考；只借节奏用词，不抄内容，**中文空格习惯不学**。
- **语气红线**：中文之间零空格、1~3 个气泡、不出现「系统告诉我 / 作为 AI」、不复述设定。

## 媒体

**分镜**（移植 dsh-video-storyboard）：可读性三档反推格数（shot 160×90 / scene 320×180 /
text 480×270），单图 640k 像素预算；编号与时间码烧进格子；底部音频包络；
同文件第二次命中缓存；`evidence.json` 可复核；`#分镜放大 <格号>` 再放大；
台词可挂到格上（B 站字幕带时间码，或外挂 ASR 命令，`{input}/{output}` 占位）。

**动图**（移植 dsh-read-animation）：解帧 → 均匀采样 → 编号 + 时间拼图；静态图会明确拒绝。

**刷站**（合并 dsh-bili-scroll + 分镜）：分区最新或关键词搜索（WBI 签名 + 匿名 buvid3）
→ 补字幕 → 打分（关键词/时长/热度/字幕量）→ 挑 → 值得的下载（优先 yt-dlp，没装用 playurl）
→ 分镜 → 日报（`data/bili/报告-日期.md`）；推过的记 `bili_seen.json` 不重复；
可设每天几点自己刷一轮，报告发你私聊。

**画图**（移植 dsh-mo-image）：适配层（openai-images / gpt-image / dall-e-3 / siliconflow /
dashscope-wanx），按「显式 → 域名 → 模型 ID → 兜底」选择；尺寸自动适配到最近合法值；
回应认 b64 / data url / 外链 / 二进制；上游不认某参数就摘掉重试，429/5xx 退避一次。

**听音频**（移植 dsh-soundcheck）：`ebur128` + `volumedetect` 算响度（LUFS）、动态（LRA）、
真峰值、平均/最大电平，按流媒体标准给一句结论，再画一张频谱图。只读本地文件，不联网。

**结果投递**：群里发指令时（分镜 / 放大 / 刷B站 / 收件箱 / 动图 / 听歌 / 画图），
图和长文本发到**发指令那个 QQ** 的私聊，群里只留一句「已经发到你私聊了」；
失败信息留在原地；私聊发不出去自动退回群里。

## 工具与集成

- **邮箱**：填一次 SMTP/IMAP + 授权码，就能收信、发信、发测试信。授权码只在面板显示「有没有」，
  留空表示不改；收件人固定为你自己（不当免费发信机）。
- **市场搜索**：提需求时（插件/功能/模块/工具 + 做/加/找/接入/实现/开发/支持）自动去
  DSH 官方目录搜一圈，把结果注入这一轮，让她说「市场里有个现成的」；搜不到就明说，禁止编造。
  默认只对专属用户触发、同句 5 分钟缓存。
- **关键词配图**：精确/模糊/正则三种匹配，命中发图；也可让模型自己决定什么时候发图。
- **群开关**：全局或单群开/关她的回复。

## 护栏与隐私

- **主人鉴权**：身份放系统级受信任位（不是塞在用户消息里，群里无法覆盖或伪造）；支持平台限定
  （QQ 的 12345 和 Telegram 的 12345 不是同一个人）；非主人的注入与冒充一律拦下。
- **工具闸门**：默认只摘「会改东西 / 会执行 / 会删」的高危工具；搜索、查状态这类照常可用。
- **发送前护栏**：敏感信息、越权内容在发出去之前清理。
- **危机优先**：识别到自伤/轻生信号，立刻放下全部傲娇，认真关心。

## 已知边界

- **媒体能力要 ffmpeg**：没装会退化成一句安装提示，不刷屏不报错。
- **凭据要你自己填**：邮箱授权码、生图 API Key 只存本机 `data/*.json`，面板上不回显。
- **B 站匿名限制**：`popular`/`ranking` 被 -352 风控拦，所以发现走分区最新；
  高清直链需要登录态，本项目只做免登录能用的部分。
- **不替用户操作账号**：自动评论、替人发消息这类功能一概不做。
- **视频消息自动识别未做**：`#分镜` 目前吃路径或链接（各适配器给视频组件的字段不一致）。
- **Whisper 不打包**：GB 级模型不进插件包，改成外挂命令（`asr_command`）。
